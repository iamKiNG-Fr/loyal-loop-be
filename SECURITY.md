# Security policy

Please report suspected vulnerabilities privately to
[security@useloyalloop.com](mailto:security@useloyalloop.com). Do not open a public
issue with customer data, credentials, proof images, order links, or exploit
details.

Include the affected URL or component, a minimal reproduction, impact, and a safe
way to contact you. We will acknowledge a valid report as soon as practical and
coordinate remediation and disclosure.

Repository administrators must enable GitHub secret scanning, push protection,
Dependabot alerts, and code scanning in **Settings → Code security**. The checked-in
workflows provide CodeQL and dependency review, but organization/repository
settings still control availability and enforcement.
